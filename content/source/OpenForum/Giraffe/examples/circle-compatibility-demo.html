Giraffe Circle Compatibility Demo

Using Traditional Script Tag (Current Pattern)

Using ES6 Modules (New Pattern)

Code Comparison

Traditional (Still Works)

// Current pattern
const canvas = new Canvas('myCanvas');
const circle = new Giraffe.Circle(100, 100, 50)
    .setColor('red')
    .setFillColor('pink');
canvas.add(circle);
canvas.repaint();

Modern ES6 (New Option)

// New pattern
import { Canvas, Circle } from 'giraffe';

const canvas = new Canvas('myCanvas');
const circle = new Circle(100, 100, 50)
    .setColor('red')
    .setFillColor('pink');
    
// New methods
console.log('Area:', circle.getArea());

canvas.add(circle);
canvas.repaint();
